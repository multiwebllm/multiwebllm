---

## 环境要求

- **Docker** 和 **Docker Compose** (v2+)
- 2GB+ 内存（建议添加 swap）
- 域名（可选，用于 HTTPS 访问）

## 安装步骤

### 1. 克隆项目

```bash
git clone https://github.com/gentpan/multiwebllm.git
cd multiwebllm
```

### 2. 配置环境变量

```bash
cp aiproxy/.env.example aiproxy/.env
```

编辑 `aiproxy/.env`，设置关键配置：

```ini
# 数据库密码（与 DB_PASSWORD 一致）
DB_PASSWORD=your-secure-db-password
DATABASE_URL=postgres://multiwebllm:your-secure-db-password@multiwebllm-db:5432/multiwebllm

# 管理后台
ADMIN_USERNAME=admin
ADMIN_PASSWORD=your-secure-password

# JWT 会话密钥（随机字符串）
JWT_SECRET=your-random-jwt-secret

# Redis
REDIS_URL=redis://multiwebllm-redis:6379
```

### 3. 启动服务

在仓库根目录执行：

```bash
# 启动 PostgreSQL 与 Redis
docker compose up -d multiwebllm-db multiwebllm-redis

# 初始化数据库表与种子数据（首次部署必须执行）
docker compose --profile init run --rm multiwebllm-init

# 构建并启动应用
docker compose up -d --build
```

等待容器就绪后，访问管理后台：

```
http://localhost:3000/login
```

### 4. 配置服务商

进入管理后台后：

1. 进入「服务商管理」页面
2. 选择要启用的 AI 服务商（如 ChatGPT、Claude 等）
3. 填入对应的 Cookie 或 Token（参考 [服务商配置](/docs/providers)）
4. 点击「测试连接」确认配置正确

### 5. 创建 API Key

1. 进入「密钥管理」页面
2. 点击「新建密钥」
3. 设置名称、配额限制
4. 复制生成的 API Key

## 第一次 API 调用

使用生成的 API Key 发起请求（`/v1` 会自动转发到 OpenAI 兼容接口）：

```bash
curl http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your-api-key" \
  -d '{
    "model": "deepseek-chat",
    "messages": [
      {"role": "user", "content": "Hello!"}
    ]
  }'
```

如果一切正常，你将收到与 OpenAI API 格式一致的 JSON 响应。
