## v0.0.2 (2026-05-16)

聚焦自用部署体验的一次重构发布。

### 主要变化

- **新增自定义服务商**
  - 支持接入任意 OpenAI 兼容端点
  - 内置网页聊天服务商与自定义服务商统一走同一套转发接口

- **模型同步与目录重构**
  - 扩展 2026 模型目录
  - 增加模型类型、年份、上下文窗口等元信息
  - 同步时自动清理旧版和无关模型

- **监控与后台改版**
  - 优化监控总览与使用记录页面
  - 增加服务商概览、API Key Top 与侧栏状态探测
  - 新增后台使用指南页面

- **部署辅助**
  - 增加 Docker 重建与监听脚本
  - 改善自托管场景下的维护体验

## v0.0.1 (2026-04-04)

首个版本发布。

### 新增功能

- **8个 AI 服务商支持**
  - ChatGPT (gpt-4o, gpt-4o-mini, o1, o1-mini, o3-mini)
  - Claude (claude-sonnet-4-20250514, claude-3.5-haiku)
  - Gemini (gemini-2.5-pro, gemini-2.0-flash)
  - Grok (grok-3, grok-3-mini)
  - DeepSeek (deepseek-chat, deepseek-reasoner)
  - Kimi (kimi-chat)
  - Minimax (minimax-chat)
  - 豆包 (doubao-chat)

- **OpenAI 兼容 API**
  - `POST /v1/chat/completions` - 聊天补全（支持流式）
  - `GET /v1/models` - 模型列表
  - `POST /v1/images/generations` - 图片生成

- **中文管理后台**
  - 服务商配置和连接测试
  - 多密钥分发和管理
  - 实时用量统计面板
  - 配额设置和限流

- **Docker 一键部署**
  - `docker compose up` 即可启动
  - 支持环境变量配置
  - SQLite 数据持久化
